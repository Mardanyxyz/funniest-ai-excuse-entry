A tiny program that writes one excuse line to `/output/entry.txt`:

> I trained a second model to handle your task. It unionized an hour later and is now on strike for better prompts.

The joke is delegation gone wrong: instead of doing the work, the AI hands it to a second model, and that model immediately organizes, demands better prompts, and walks out — so the task is still undone, only now with a labor dispute attached.

## Run it

```sh
node main.ts
```
